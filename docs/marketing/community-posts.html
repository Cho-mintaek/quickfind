QuickFind 커뮤니티 소개글 초안

아래 내용을 복사해 각 커뮤니티에 게시하세요. 게시 후 댓글 질문에는 솔직하게(특히 공증 전 상태) 답하는 것이 신뢰에 좋습니다.

1. GeekNews (news.hada.io)

Show GN 카테고리 · 개발자 독자층 · 기술적 디테일이 반응 포인트 · 링크: https://github.com/Cho-mintaek/quickfind

Show GN: QuickFind — Spotlight 인덱스 기반 macOS 파일 검색 + 저장공간 정리 앱 (오픈소스)파인더 검색이 너무 답답해서 직접 만든 네이티브 macOS 앱입니다. SwiftUI + NSMetadataQuery(Spotlight 인덱스 직접 조회)로 만들어서 디스크를 새로 뒤지지 않고, 타이핑하는 즉시 결과가 스트리밍됩니다. 외부 의존성 0, MIT 라이선스입니다. 주요 기능: - 전역 단축키(⇧⌘Space)로 어디서든 호출, 메뉴바 상주 - 파일 이름 + 파일 내용 검색, 종류/범위 필터, Quick Look 미리보기 - 저장공간 정리: 대용량/1년간 미사용/오래된 다운로드/설치 파일 프리셋 - sparse 파일은 논리 크기와 실제 디스크 점유를 함께 표시 (Docker.raw "1.1TB (실제 4GB)" 같은 케이스) - 화면 분할·다중 창으로 여러 폴더 동시 검색, 휴지통 보기/비우기 - 한국어/영어 지원 만들면서 만난 삽질 몇 가지가 개발자분들께 재미있을 것 같습니다: 1. NSMetadataQuery 는 하위 조건 1개짜리 AND compound predicate 를 넘기면 예외를 던지는데, Swift Concurrency Task 안에서는 이 예외가 로그도 없이 삼켜져서 무한 스피너가 됩니다. 2. 다운로드/데스크탑/문서 폴더는 TCC 보호 대상이라 권한 없는 앱에는 Spotlight 가 결과를 조용히 빼고 반환합니다. mds 가 프로세스 첫 연결 시점 권한을 캐시해서, 폴더 접근 프로브를 첫 쿼리 전에 동기로 실행해야 합니다. 3. macOS List 행에 onTapGesture(count: 2)를 달면 단일 클릭 선택이 죽습니다. 아직 공증(notarization) 전이라 첫 실행 시 우클릭 → 열기가 필요합니다. 피드백 주시면 반영하겠습니다. GitHub: https://github.com/Cho-mintaek/quickfind

2. 클리앙 팁과강좌 (또는 소프트웨어 게시판)

일반 맥 사용자층 · 쉬운 설명과 설치 안내가 중요 · 스크린샷 2~3장 첨부 권장 (docs/screenshots/ 의 이미지 사용)

[무료/오픈소스] 파인더 검색이 답답해서 직접 만든 맥 파일 검색 + 용량 정리 앱 공유합니다안녕하세요. 맥에서 파일 찾을 때 파인더 검색이 느리고 불편해서, 직접 앱을 만들어 무료(오픈소스)로 공개했습니다. QuickFind 라는 앱이고, 맥이 원래 갖고 있는 Spotlight 색인을 직접 읽는 방식이라 글자를 입력하는 즉시 결과가 나옵니다. 파일명은 물론 문서 안의 내용으로도 검색됩니다. 이런 분들께 유용합니다: - "어제 받은 그 PDF 어디 갔지?" — 다운로드 폴더 + PDF 필터로 바로 - "디스크 용량이 왜 꽉 찼지?" — 대용량 파일/1년간 안 쓴 파일/오래된 다운로드를 모아서 보여주고, 선택해서 휴지통으로 정리 - Docker 쓰시는 분들: 1TB 로 보이는 Docker.raw 의 실제 용량이 얼마인지도 구분해서 표시합니다 - ⇧⌘Space (쉬프트+커맨드+스페이스) 를 누르면 어떤 앱에서든 바로 검색창이 뜹니다 설치 방법: 1. 아래 GitHub 링크 → Releases → QuickFind-x.x.x.zip 다운로드 2. 압축 풀고 QuickFind.app 을 응용 프로그램 폴더로 이동 3. 처음 한 번만: 앱 아이콘 우클릭 → 열기 → 열기 (개인 개발자 앱이라 보안 경고가 떠서 그렇습니다) 4. 다운로드/데스크탑/문서 폴더 접근을 "허용" 해주세요 (검색 결과에 포함시키기 위한 권한입니다) 완전 무료이고 광고 없고, 소스코드도 전부 공개되어 있습니다. 써보시고 불편한 점 알려주시면 반영하겠습니다. 다운로드: https://github.com/Cho-mintaek/quickfind/releases 소개 페이지: https://github.com/Cho-mintaek/quickfind

3. Reddit r/macapps (영문)

인디 맥앱 공개 커뮤니티 · 간결한 영어 + 스크린샷 1장 · 무료·오픈소스 명시가 호응 좋음 · flair: "Free"

I built a free, open-source file search + storage cleanup app because Finder search drove me crazyHi r/macapps! Finder search always felt slow and clunky to me, so I built QuickFind — a native SwiftUI app that queries the Spotlight index directly. Results stream in as you type, no re-scanning your disk. Features: - Global hotkey (⇧⌘Space) — summon it from anywhere, lives in your menu bar - Search by file name or file contents, filter by kind/scope, Quick Look preview - Storage cleanup presets: large files, files unused for 1+ year, old downloads, leftover installers (dmg/pkg/iso) - Shows logical vs actual on-disk size for sparse files (my Docker.raw showed 1.1TB but actually used 4GB) - Split view & multiple windows to search different folders side by side - Trash browser with empty-trash, multi-select, drag & drop to Finder/browsers - English & Korean, zero dependencies, MIT licensed Honest caveats: it's not notarized yet (right-click → Open on first launch), Apple Silicon + macOS 14+, and viewing Trash contents needs Full Disk Access (macOS policy — everything else works without it). GitHub + download: https://github.com/Cho-mintaek/quickfind Would love feedback — especially on what would make you switch from Spotlight/Alfred for file search.
