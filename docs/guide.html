QuickFind

macOS Spotlight 인덱스 기반 초고속 파일 검색 앱 · v1.0

소개

QuickFind 는 파인더의 느리고 불편한 검색을 대체하는 네이티브 macOS 앱입니다. 도서관에서 책을 찾을 때 서가를 일일이 뒤지는 대신 색인 카드를 펼치는 것처럼, QuickFind 는 macOS 가 항상 유지하는 Spotlight 인덱스를 직접 조회하기 때문에 타이핑하는 즉시 결과가 나타납니다. 디스크를 새로 뒤지는 과정이 없습니다.

  • 실시간 검색 — 입력 후 0.25초 안에 검색 시작, 결과가 모이는 대로 즉시 표시
  • 종류 필터 — 폴더 / 문서 / PDF / 이미지 / 동영상 / 음악 / 압축 파일 / 앱
  • 검색 범위 — 전체 Mac / 홈 폴더 / 데스크탑 / 문서 / 다운로드
  • 파일 내용 검색 — 파일 이름뿐 아니라 문서 내부 텍스트까지 검색 (체크박스)
  • Quick Look 미리보기 — 선택한 파일의 실제 내용을 우측 패널에서 바로 확인
  • 키보드 중심 사용성 — 마우스 없이 검색→선택→열기까지 완결
  • 드래그 앤 드롭 — 결과 파일을 파인더·브라우저 등 외부로 그대로 끌어다 놓기
  • 저장공간 정리 — 대용량 / 오래 사용 안 한 파일 / 오래된 다운로드 / 설치 파일을 모아 보고 휴지통으로 정리
  • 다중 선택 — ⌘클릭 개별 추가, ⇧클릭 범위 선택, 합계 용량 표시, 일괄 휴지통 이동

설치 및 실행

앱은 이미 /Applications/QuickFind.app 에 설치되어 있습니다.

  • Spotlight(⌘ Space)에서 "QuickFind" 를 입력해 실행
  • 또는 파인더 → 응용 프로그램 → QuickFind 더블클릭
  • 자주 쓴다면 Dock 아이콘을 우클릭 → 옵션 → "Dock 에 유지"

사용법

기본 검색

  1. 앱을 열면 검색창에 자동으로 커서가 놓입니다. 바로 입력하세요.
  2. 한글·영문 모두 지원하며 대소문자를 구분하지 않습니다.
  3. 결과는 기본적으로 최근 수정순으로 정렬됩니다. 우측 상단에서 이름순 · 크기순으로 변경할 수 있습니다.

어디서든 호출 (전역 단축키·메뉴바)

어떤 앱을 쓰고 있어도 ⌥ Space 를 누르면 QuickFind 가 검색창 포커스 상태로 나타나고, 다시 누르면 숨겨집니다. 메뉴바의 원형 돋보기 아이콘을 좌클릭해도 같은 동작이며, 우클릭 메뉴에서 전역 단축키 켜기/끄기와 Dock 아이콘 숨기기(메뉴바 전용 모드)를 설정할 수 있습니다. 창을 닫아도 앱은 메뉴바에 남아 있으므로, 완전히 종료하려면 우클릭 → "QuickFind 종료" 또는 ⌘ Q 를 사용하세요.

저장공간 정리

사이드바 맨 아래 저장공간 정리 섹션에서 프리셋을 선택하면 검색어 없이도 바로 조회됩니다. 다시 클릭하면 해제됩니다.

  • 대용량 파일 — 100MB 이상, 크기순
  • 오래 사용 안 한 파일 — 1년 이상 열지 않은 1MB 이상 파일, 오래된 순
  • 오래된 다운로드 — 다운로드 폴더에 6개월 이상 방치된 파일
  • 설치 파일·디스크 이미지 — dmg·pkg·iso 등 설치 후 지워도 되는 파일

하단 상태바에 표시 항목의 합계 용량이 나오고, 여러 개를 선택하면 선택 합계도 보입니다. 종류 필터·검색어와 조합할 수 있어 "대용량 + 동영상"처럼 좁혀갈 수 있습니다. 휴지통 이동은 항상 확인 창을 거치며, 휴지통에서 복원 가능합니다.

휴지통 보기·비우기

저장공간 정리 섹션의 휴지통을 누르면 휴지통 안 파일 목록이 보이고, 항목별 영구 삭제와 상단의 휴지통 비우기를 쓸 수 있습니다. 모두 확인 창을 거치며, 영구 삭제는 되돌릴 수 없습니다.

  • 휴지통 목록 보기에는 macOS 정책상 전체 디스크 접근 권한이 필요합니다. 화면의 안내 버튼으로 설정을 열어 QuickFind 를 켠 뒤 "다시 확인"을 누르세요.
  • 휴지통 비우기는 권한 없이도 Finder 를 통해 동작합니다 (첫 실행 시 "Finder 제어 허용" 프롬프트 1회).
  • 휴지통 항목의 복원은 "Finder에서 보기"로 휴지통을 연 뒤 우클릭 → 되돌려 놓기를 이용하세요.

범위와 필터

왼쪽 사이드바에서 종류(파일 형식)와 검색 범위(폴더)를 조합할 수 있습니다. 예를 들어 "다운로드 폴더에 받아둔 PDF" 는 종류 → PDF, 검색 범위 → 다운로드를 선택한 뒤 파일 이름 일부만 입력하면 됩니다.

팁 — 결과가 너무 많으면 범위를 좁히는 것이 가장 효과적입니다. 기본 범위는 "홈 폴더"이며, "전체 Mac"은 시스템 영역까지 포함해 결과가 많아집니다.

파일 내용 검색

검색창 아래 "파일 내용 포함" 을 체크하면 파일 이름에 검색어가 없어도 문서 안의 텍스트에 검색어가 있으면 결과에 나타납니다. PDF·워드·한글 텍스트·소스 코드 등 Spotlight 가 인덱싱하는 모든 형식이 대상입니다.

문제 해결

다운로드·데스크탑·문서 폴더 파일이 검색되지 않아요

이 세 폴더는 macOS 개인정보 보호 대상이라, 앱에 폴더 접근 권한이 없으면 Spotlight 결과에서 조용히 제외됩니다. QuickFind 는 시작할 때 세 폴더에 접근 권한을 요청하므로 보통 자동으로 해결되지만, 만약 계속 안 보이면 시스템 설정 → 개인정보 보호 및 보안 → 파일 및 폴더에서 QuickFind 에 해당 폴더 권한이 켜져 있는지 확인하세요. 가장 확실한 방법은 전체 디스크 접근 권한(Full Disk Access)에 QuickFind 를 추가하는 것입니다. 권한을 바꾼 뒤에는 앱을 재시작해야 결과에 반영됩니다.

있어야 할 파일이 검색되지 않아요

Spotlight 인덱스에서 제외된 폴더는 QuickFind 에서도 보이지 않습니다. 시스템 설정 → Spotlight → 검색 개인 정보 보호에서 해당 폴더가 제외 목록에 있는지 확인하세요. 인덱스가 손상된 것 같다면 터미널에서 재색인할 수 있습니다: 

sudo mdutil -E /

결과 개수 표시

성능을 위해 화면에는 상위 500개까지만 표시합니다. 하단 상태바에 "23,543개 중 500개 표시"처럼 전체 개수가 함께 나오니, 원하는 파일이 안 보이면 검색어를 더 구체적으로 입력하세요.

소스에서 다시 빌드하기

프로젝트는 ~/dev/mintaek/quickfind 에 있으며, Swift Package Manager 로 빌드합니다.

cd ~/dev/mintaek/quickfind
./scripts/make_app.sh          # 릴리즈 빌드 + .app 번들 생성
cp -R build/QuickFind.app /Applications/   # 재설치

주요 구조: Search/SearchEngine.swift (NSMetadataQuery 래퍼), UI/ (SwiftUI 뷰), Models/ (카테고리·범위·정렬 정의), scripts/make_app.sh (번들 패키징 + 아이콘 생성 + ad-hoc 서명).
